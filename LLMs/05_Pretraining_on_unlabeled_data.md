# Decoding strategies to control randomness
We would learn temperature scaling and top-k sampling to improve the generate_text_simple function

## Temperature scaling
This is a technique that adds a probabilistic selection process to the next-token generation task. Inside the generate_text_simple function, we always sampled the token with the highest probability as the next token using torch.argmax, also known as greedy decoding. To generate text with more variety, we can replace argmax with a function that samples from a probability distribution.

In normal operations, the logit returned by the model is converted into probabilities by the softmax function and the obtained token id is then converted back into generated token using argmax. To implement the probabilist sampling process, we can replace argmax with the multinomial function.

"Temperature scaling is just a fancy word used to divide the logits with a number greater than 0. If the value is greater then 1 then it results in a broader distribution, however if the value is less than 1 then it results in a sharper distribution"

So if the temperature is low i.e. 0.1 then the distribution will be sharper and the model will most probably select the token which has highest probability for almost 100% of the time.

## Top-k sampling
We've implemented a probabilistic sampling approach coupled with temperature scaling to increase the diversity of the outputs. We saw that higher temperature values result in more uniformly distributed next-token probabilities, which result in more diverse outputs as it reduces the likelihood of the model repeatedly selecting the most probable tokens. This allows exploring more creative paths. However if the distribution is flat then there are more chances that the output will be gramatically incorrect.

To avoid this, temperature scaling is combined with top k sampling approach, which masks the tokens which have very low probability of selection thus eliminating the tokens which are completely irrelevant. In top-k only top k token are eligible for selection and the remaining tokens are masked.
